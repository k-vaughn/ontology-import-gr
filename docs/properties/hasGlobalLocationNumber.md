# hasGlobalLocationNumber

The Global Location Number (GLN, sometimes also referred to as International Location Number or ILN) of the respective gr:BusinessEntity or gr:Location.
The Global Location Number is a thirteen-digit number used to identify parties and physical locations.

**Domain**: [BusinessEntity](../classes/BusinessEntity.md) or [Location](../classes/Location.md) or [schema1:Organization](https://w3id.org/citydata/imported/schema1/Organization) or [schema1:Place](https://w3id.org/citydata/imported/schema1/Place)

**Range**: [xsd:string](https://w3id.org/citydata/imported/xsd/string)
